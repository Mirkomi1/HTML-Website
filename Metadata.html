Page 9: Metadata Tags (Inside <head>)

Tag <meta>

Definition

Supplies machine-readable metadata about the HTML document to browsers and search engines.

Attributes

Attribute Role
charset Sets the document character encoding (usually "UTF-8").
name Specifies the metadata name (such as "viewport" or "description").

Example

Code: 
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Result:

Meta tags work behind the scenes in head and have no visible output.
