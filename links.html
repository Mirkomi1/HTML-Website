Page 3: Links

Tag <a>

Definition

Creates a clickable hyperlink that directs the user to another page or external URL.

Attributes

Attribute Role
href Specifies the destination URL of the link.
target Setting "_blank" opens the linked document in a new tab.

Example

Code: 
<a href="https://www.wikipedia.org" target="_blank">Visit Wikipedia</a>
Result: Visit Wikipedia
