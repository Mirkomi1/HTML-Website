Page 5: Table Tags

Tag <table>

Definition

Creates a table container to display structured data in rows and columns.

Attributes

Attribute Role
border Specifies the border width (legacy attribute, styled via CSS).

Example

Code: 
<table>
  <tr>
    <th>Name</th>
    <th>Role</th>
  </tr>
  <tr>
    <td>John</td>
    <td>Developer</td>
  </tr>
</table>
Result:
Name Role
John Developer
