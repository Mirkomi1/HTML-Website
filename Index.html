Page 1: Структура страницы

Базовые элементы, определяющие скелет и корневые границы любого HTML-документа.

<html>

Definition

Корневой элемент документа, содержащий в себе все остальные HTML-теги веб-страницы.

Attributes

Attribute Role
lang Определяет основной естественный язык содержимого страницы (например, "ru" или "en").
dir Задает направление чтения текста (ltr — слева направо, rtl — справа налево).

Example

Code
<!DOCTYPE html>
<html lang="ru">
  <head>
    <title>Пример</title>
  </head>
  <body>
    <p>Контент документа</p>
  </body>
</html>
Result

Документ успешно загружен в корневой контейнер html.

<body>

Definition

Представляет тело документа и содержит весь видимый пользователю интерфейс и контент страницы.

Attributes

Attribute Role
class Назначает один или несколько CSS-классов для стилизации всего содержимого страницы.
id Уникальный глобальный идентификатор тела страницы для скриптов и стилей.

Example

Code
<body class="main-page">
  <p>Видимый контент страницы</p>
</body>
Result

Видимый контент страницы
