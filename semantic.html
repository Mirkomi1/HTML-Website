Page 8: Semantic Layout Tags

Tag <header>

Definition

Represents introductory content or navigation links for the page or section.

Attributes

Attribute Role
class Applies CSS styling to the header section container.

Example

Code: 
<header>
  <h4>Section Title</h4>
</header>
Result:

Section Title
