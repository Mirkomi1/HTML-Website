Page 6: Form Elements

Tag <input>

Definition

An interactive form element used to receive various types of input data from the user.

Attributes

Attribute Role
type Defines the type of input field (e.g., text, password, checkbox).
placeholder Shows temporary hint text inside the field before user input.

Example

Code: 
<input type="text" placeholder="Enter your name">
