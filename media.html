Page 7: Multimedia Tags

Tag <img>

Definition

Embeds a graphic image file directly into the HTML web page.

Attributes

Attribute Role
src Specifies the relative or absolute path to the image file.
alt Provides alternative text if the image fails to load.

Example

Code: 
<img src="images/sample.jpg" alt="Sample picture" width="120">
