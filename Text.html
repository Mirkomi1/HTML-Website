Page 2: Text Formatting Tags

Tag <p>

Definition

Defines a text paragraph and adds default vertical space above and below it.

Attributes

Attribute Role
title Displays a tooltip when hovering the mouse over the paragraph.

Example

Code: 
<p title="Info">This is a sample paragraph.</p>
Result:

This is a sample paragraph.

Tag <strong>

Definition

Marks text with strong importance or urgency, rendered in bold font by browsers.

Attributes

Attribute Role
class Applies custom CSS styling to the highlighted text.

Example

Code: 
<p>Warning: This is <strong>important</strong>!</p>
Result:

Warning: This is important!
