Page 4: List Tags

Tag <ul>

Definition

Defines an unordered (bulleted) list of items where order does not matter.

Attributes

Attribute Role
class Used to change bullet icons via CSS properties.

Example

Code: 
<ul>
  <li>Coffee</li>
  <li>Tea</li>
</ul>
Result:
  • Coffee
  • Tea

Tag <ol>

Definition

Defines an ordered (numbered) list of items arranged in numerical sequence.

Attributes

Attribute Role
start Sets the starting number of the list.

Example

Code: 
<ol start="1">
  <li>First step</li>
  <li>Second step</li>
</ol>
Result:
  1. First step
  2. Second step
